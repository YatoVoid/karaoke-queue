Setup order: set a currency, add your tables and pair each one to a device, create a player link for the speakers, then optionally add background music for when no one's playing anything.

1. Currency

Shown next to every price, so a number like "2" reads as an actual amount.

2. Tables

Each table's link is what its guests use to request songs. Press Pair to get one, then leave that table's device (a tablet, a kiosk) open on it.
